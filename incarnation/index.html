何謂降生

何謂「降生」

「聖言成了血肉」(若 1:14)——天主聖子取人性，為在人性內救我們，這一事實稱為「道成人身」。教會以聖保祿所記載的一首歌曲來讚頌降生的奧跡：「你們該懷有基督耶穌所懷有的心情：祂雖具有天主的形體，並沒有以自己與天主同等，為應當把持不捨的，卻使自己空虛，取了奴僕的形體，與人相似，形狀也一見如人；祂貶抑自己，聽命至死，且死在十字架上」(斐 2:5-8)。
——天主教教理 461
耶穌基督降生成人・聖心堂慕道班5 / 23
講解：降生不是神話，是天主進入歷史的行動：永恆的聖子取了我們的人性。

在起初已有聖言

在起初已有聖言，聖言與天主同在，聖言就是天主。聖言在起初就與天主同在。萬物是藉着他而造成的；凡受造的，沒有一樣不是由他而造成的。在他內有生命，這生命是人的光。光在黑暗中照耀，黑暗決不能勝過他。
——若望福音 1:1-5

聖言

聖言成了血肉

  • 「寄居」原文是「支搭帳幕」
  • 舊約天主的帳幕臨於以色列中間——如今天主親自「住」進了人類歷史
  • 「那普照每人的真光，正在進入這世界」(若 1:9)
  • 不是遠遠地愛，是走進來愛
於是，聖言成了血肉，寄居在我們中間；我們見了他的光榮，正如父獨生者的光榮，滿溢恩寵和真理。
——若望福音 1:14

講解：基督信仰最驚人的宣告：創造宇宙的聖言，成了可以看見、可以觸摸的人。
真天主真人

真天主，亦真人

天主子降生成人是唯一及無與倫比的事件，但並不是說耶穌基督一部分是天主，一部分是人；也不是天主性和人性的模糊的混合產物。祂確實成了人，但仍是真正的天主。耶穌基督是真天主，又是真人。教會也這樣撮要：「耶穌基督在其唯一的天主性位格中，是真天主又是真人；為這緣故，祂是天主與人之間的唯一中保。」
——天主教教理 464、480
耶穌基督降生成人・聖心堂慕道班8 / 23
講解：不是一半天主、一半人，也不是天主穿上人的外衣——祂是真天主，又是真人。

誕生在馬槽

喬托《耶穌誕生》(1305，斯克羅威尼禮拜堂）
便生了她的頭胎男兒，用襁褓裹起，放在馬槽裏，因為在客棧中為他們沒有地方。在那地區有些牧人露宿，守夜看守羊群。有上主的一個天使站在他們身邊，上主的光耀環照着他們。天使向他們說：「不要害怕！看！我給你們報告一個為全民族的大喜訊：今天在達味城中，為你們誕生了一位救世者，他是主默西亞。這是給你們的記號：你們將要看見一個嬰兒，裹着襁褓，躺在馬槽裏。」忽有一大隊天軍，同那天使一起讚頌天主說：「天主受享光榮於高天，主愛的人在世享平安！」

虛己

祂使自己空虛

你們該懷有基督耶穌所懷有的心情：他雖具有天主的形體，並沒有以自己與天主同等，為應當把持不捨的，卻使自己空虛，取了奴僕的形體，與人相似，形狀也一見如人；他貶抑自己，聽命至死，且死在十字架上。為此，天主極其舉揚他，賜給了他一個名字，超越其他所有的名字，致使上天、地上和地下的一切，一聽到耶穌的名字，無不屈膝叩拜；一切唇舌無不明認耶穌基督是主，以光榮天主聖父。
——斐理伯書 2:5-11
耶穌基督降生成人・聖心堂慕道班14 / 23
講解：「空虛自己」——沒有失去天主性，卻甘願取了人性的一切軟弱：飢餓、疲倦、流淚，甚至死亡。為此，天主舉揚祂，賜下超乎萬名之上的名字。

為什麼降生・一

為救我們脫離罪惡

  • 「耶穌」按希伯來語解說：「天主拯救」(CCC 430)
  • 「她要生一個兒子，你要給他起名叫耶穌，因為他要把自己的民族，由他們的罪惡中拯救出來。」（瑪 1:21）
聖言成了血肉，是為拯救我們，使我們與天主和好：是天主「愛了我們，且打發自已的兒子，為我們做贖罪祭」(若一 4:10)。「父打發了子來作世界的救主」(若一 4:14)。
——天主教教理 457
耶穌基督降生成人・聖心堂慕道班16 / 23
講解：第一個理由：我們的本性患了病，需要醫治；成了俘虜，需要一位救主。
為什麼降生・二

為使我們認識天主的愛

  • 「天主竟這樣愛了世界，甚至賜下了自己的獨生子，使凡信他的人不至喪亡，反而獲得永生。」（若 3:16）
  • 降生是天主之愛最高、最清楚的證明
聖言成了血肉，是為使我們因此認識天主的愛：「天主對我們的愛在這事上已顯示出來：就是天主把自己的獨生子，打發到世界上來，好使我們藉著祂得到生命」(若一 4:9)。
——天主教教理 458
耶穌基督降生成人・聖心堂慕道班17 / 23
講解：第二個理由：愛不只用說的——天主把獨生子賜下，這就是愛的證明。
為什麼降生・三

為作我們效法的榜樣

  • 「我是道路、真理、生命，除非經過我，誰也不能到父那裡去。」（若 14:6）
  • 祂先走過人生的路，我們才能跟著祂走
聖言成了血肉，是為作我們聖德的模範：「你們該彼此相愛，如同我愛了你們一樣」(若 15:12)。
——天主教教理 459
耶穌基督降生成人・聖心堂慕道班18 / 23
講解：第三個理由：祂不只指路，祂親自走在前面。
為什麼降生・四

為使我們有分於天主的性體

  • 「原來天主子成了人，是為使我們成為天主」
  • 「天主的獨生子，為了要使我們分享祂的天主性，便取了我們的人性」
  • 祂成為人，為使我們成為天主的兒女
聖言成了血肉，是為使我們「成為有分於天主性體的人」。
——天主教教理 460
